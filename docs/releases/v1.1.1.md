# v1.1.1 — 2026-05-26 Data Archive + Flight Links

## Status

- Production URL: https://conference-map.vercel.app
- Release type: patch
- Verification: `npx tsc --noEmit`

## Summary

This release corrects the dashboard data to the 2026-05-26 state, moves completed conferences into archive-style handling, and adds direct Google Flights search links for overseas conference airfare rows.

## Data updates

### Completed / archive updates

- **SEABW 2026**
  - Status changed from `upcoming` to `completed`.
  - Official visible scale used: `4,000+` attendees, `200+` speakers, `40+` sponsors, `110+` partners, `60+` side events.
  - `sideEvents.count` changed from `16` listed examples to `60` official aggregate.
  - Feed and action items changed to post-event follow-up/archive mode.

- **TOKEN2049 Dubai 2026**
  - Event remained cancelled / postponed.
  - 2026 side-event trend corrected to `0` because the event did not actually run.

- **WebX 2025 archive data**
  - Corrected to official archive figures provided by screenshot/reference:
    - Attendees: `14,115`
    - Side events: `170+`
    - Sponsors: `165`
    - Media partners: `56`
    - Speakers: `270+`
    - Countries: `99`

- **Consensus / EthCC archive semantics**
  - Archive sections corrected to reference prior-year archive data instead of self-referencing the current 2026 event.

### Side-event trend updates

- Added 2026 values across all event `sideEventTrend` arrays.
- Completed events use actual/official counts when available.
- Upcoming events use projection values derived from prior-year trend or currently visible side-event listings.

## UI updates

- Added a small external-link icon next to the `항공권` budget item for non-domestic events.
- The link opens Google Flights for:
  - Origin: `ICN`
  - Destination: mapped city airport code
  - Departure: event start date
  - Return: day after event end date
  - Currency: `KRW`
- Domestic events hide the flight link.
