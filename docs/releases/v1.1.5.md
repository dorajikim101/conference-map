# v1.1.5 - Timeline Synchronization + Close-Date Layout

Release date: 2026-05-28

## Summary

This release stabilizes the conference timeline layout after the S/A/B lane redesign. The timeline now uses S tier as the left lane and A/B as the right lane while preserving a shared date scale, so users can judge whether closely overlapping events are practical to attend in one trip.

## Changes

- Split timeline lanes into:
  - Left: S tier
  - Right: A tier and B tier
- Added compact A/B cards:
  - A cards render at a medium size
  - B cards render as compact cards
  - Off-screen A/B events collapse to mini cards
- Kept A/B “magnifying glass” behavior:
  - Events near the viewport expand
  - Events outside the viewport collapse
- Reworked timeline positioning:
  - Different lanes use the same linear date scale
  - Close dates stay visually close by day difference
  - Cards within the same lane still avoid overlap
- Added a red `TODAY` marker across the timeline.
- Event selection now scrolls the selected event near the top of the timeline.
- Removed S/A/B tier badges from event images because lane position already communicates tier.

## Fixes

- Fixed S vs A/B lane desynchronization on later months.
- Fixed card content disappearing after tier-badge removal.
- Fixed scroll lock caused by selection auto-scroll repeatedly firing during A/B viewport expansion.

## Verification

- `npx tsc --noEmit`
- `npm run build`
