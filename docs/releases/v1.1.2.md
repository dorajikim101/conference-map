## Summary

## Correction

- The official SEABW homepage shows `60+ Side Events`, but this appears in the event scale/marketing stats section, not as a post-event final archive report.
- The official side-events page embeds the SEABW Luma calendar.
- Luma calendar API count as of 2026-05-26:
  - `26` events during the official SEABW week window (`2026-05-18` through `2026-05-24`).
  - `32` total 2026 calendar listings when including pre-week roadshow/press events and post-week/future listings.
- Dashboard now uses `26` as the verified side-event count for SEABW 2026.

## Data changes

- `src/lib/events.ts`

  - SEABW label: official Luma week-window verified count
  - SEABW side-event trend 2026 value: `60` → `26`
